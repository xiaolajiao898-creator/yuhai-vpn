安装步骤

安卓怎么装

  1. 下载安装包。用手机浏览器点上面的「下载安卓版」，等下载完成。
  2. 允许安装。手机提示「禁止安装未知应用」时，按提示允许当前浏览器安装应用。
  3. 完成安装。回到下载的文件，点「安装」。
  4. 打开宇海注册。账号填你自己钱包的 USDT（TRC20）地址，再设置密码。
安装步骤

Windows 怎么装

  1. 下载安装包。在电脑上点上面的「下载 Windows 版」。
  2. 运行安装程序。出现蓝色的「Windows 已保护你的电脑」时，点「更多信息」→「仍要运行」。
  3. 允许管理员权限。安装和每次打开时，系统询问是否允许更改，点「是」。
  4. 登录或注册。账号是你自己钱包的 USDT（TRC20）地址，密码自己设置，然后选线路连接。
