# 网页注册部署说明

官网可以自己开户。账户仍然是用户自己的 TRON TRC20 地址加自设密码，之后在安卓或 Windows 客户端用同一地址和密码登录。这次**没有数据库迁移**。

## 接口

新增两个公开接口，都不创建设备、不返回令牌：

- `POST /v1/auth/web/challenge`：签发一道 SHA-256 工作量证明。算法 `sha256-lzbits-v1`，难度 16（普通手机通常一两秒算完，慢的旧手机约十秒内），题目 3 分钟内有效，并绑定签发时看到的客户端 IP。
- `POST /v1/auth/web/register`：校验地址、密码和证明后开户。`challenge_id` 同时是幂等键。

地址校验与 App 相同（`T` 开头的 34 位 Base58Check）。密码至少 8 个字符，且同时包含字母和数字。邀请码可选；无效时仍然开户，`invite_bound` 为 false。

注册限流与 App 注册共用：每个 IP 每小时 5 次，每个 /24 网段每小时 30 次。取题目单独计数（每个 IP 每小时 30 次，每个网段每小时 120 次），避免刷新页面把注册额度用完。预检不计入限额。

网页登录、退出和账户接口的跨域只放行精确来源 `https://yhvpn.io`，并允许携带 Cookie。其他接口不返回跨域头。注册表单里有一个对用户隐藏的蜜罐字段；填了它会得到和证明失败一样的提示，并且这道题作废。

## 上线步骤

1. 拉包含本次改动的版本，重新构建并重启 API 进程（现有的 `app-api` 服务）。不要改数据库角色，也不要执行 goose。
2. 把静态文件覆盖到线上站点（站点是手写 HTML，不要用 `apps/website` 的构建结果覆盖）：
   - `deploy/site-patch/index.html` → 站点根目录的 `index.html`
   - `deploy/site-patch/download/index.html` → 站点的 `download/index.html`
   - `deploy/site-patch/register/index.html` → 站点的 `register/index.html`
   - `deploy/site-patch/login/index.html` → 站点的 `login/index.html`
   - `deploy/site-patch/account/index.html` → 站点的 `account/index.html`
   - `deploy/site-patch/i/index.html` → 站点的 `i/index.html`
   - `deploy/site-patch/assets/site.css` → 站点的 `/assets/site.css`
   - `deploy/site-patch/assets/web-login.js` → 站点的 `/assets/web-login.js`
   - `deploy/site-patch/assets/web-account.js` → 站点的 `/assets/web-account.js`
3. 注册脚本必须是同域外部文件，不要写进 HTML。把 `deploy/site-patch/register/register.js` 上传为站点的 `/register/register.js`。页面用 `<script src="/register/register.js"></script>` 引用。登录和用户中心分别引用 `/assets/web-login.js` 与 `/assets/web-account.js`。线上 `script-src 'self'` 会拦住没有 `src` 的 `<script>`。站点 CSP 需要 `connect-src 'self' https://api.yhvpn.io`，否则浏览器会拦住这些请求。
4. 不要把密钥、`.env`、服务器地址写进仓库或提交说明。

`apps/website` 里有一份同样的注册页，方便以后官网改用构建产物时对齐。当前线上站不以它为准。

## 上线后核对

允许的来源应返回 204，并且 `Access-Control-Allow-Origin` 与请求来源逐字相同：

```bash
curl -sS -D - -o /dev/null -X OPTIONS https://api.yhvpn.io/v1/auth/web/challenge \
  -H 'Origin: https://yhvpn.io' \
  -H 'Access-Control-Request-Method: POST' \
  -H 'Access-Control-Request-Headers: Content-Type'
```

其他来源应返回 403，且响应里没有 `Access-Control-Allow-Origin`。然后打开 `https://yhvpn.io/register/`，用自己的钱包地址走一遍注册，再到安卓或 Windows 客户端用该地址和密码登录。邀请链接用 `https://yhvpn.io/register/?code=邀请码`，注册页会自动填上。
